Async/Await & Promises Practice

What are Promises? Promises are objects that represent the eventual completion (or failure) of an asynchronous operation and its resulting value.

What is Async/Await? Async/await is a syntactic feature that allows you to write asynchronous code that looks synchronous, making it easier to read and understand.

1. Basic Promise Example

function fetchGrocery(id) {
  return new Promise((resolve, reject) => {
    // Simulate API call with setTimeout
    setTimeout(() => {
      if (id > 0 && id <= 10) {
        const grocery = { id, name: 'Apple', price: 2.99 };
        resolve(grocery);
      } else {
        reject('Grocery not found');
      }
    }, 1000);
  });
}

2. Async/Await Example

async function getGroceryData(id) {
  try {
    const response = await fetchGrocery(id);
    return response;
  } catch (error) {
    throw error;
  }
}

3. Promise Chaining

fetchGrocery(1)
  .then(grocery => {
    console.log('Got grocery:', grocery);
    return addTax(grocery);
  })
  .then(groceryWithTax => {
    console.log('After tax:', groceryWithTax);
    return applyDiscount(groceryWithTax);
  })
  .then(finalGrocery => {
    console.log('Final price:', finalGrocery);
  })
  .catch(error => console.error(error));
